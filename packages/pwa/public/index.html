This app talks to your own Turso database, directly from this browser. There is no todocloud server, no account, and nothing in the middle: your tasks go from this tab to your database and nowhere else.

What you are accepting

  • The token is stored in this browser. Any script that runs on this site can read it, and so can anyone who opens devtools on this device. The protection here is that this site serves a handful of hand-written files and no third-party code — not that the value is hidden from anything.
  • Use a token that is as narrow and as short-lived as you can make it. Turso issues tokens per database, which is why it is the provider this app supports: a token minted for your todo database cannot touch anything else you own. Give it an expiry — turso db tokens create <database> --expiration 7d — and mint a read-only one if you only want to look (--read-only).
  • Anyone who unlocks this device can see your tasks. Leave the box below unchecked on a shared or borrowed machine: the token is then kept for this tab only and goes when you close it.
  • Revoking is done at Turso, not here. Disconnecting removes this browser's copy of the token. It does not end the token's life — turso db tokens invalidate <database> does.

From turso db show <database> --url. The URL is remembered on this device; it is not a credential. A token is never put in it — a URL is logged by every proxy it passes, so this app refuses a URL that carries one.

From turso db tokens create <database>. It is sent as an Authorization header to your database and to nowhere else.

Unchecked — the default — keeps it for this tab only, so closing the tab forgets it. Checked, it survives until you disconnect or the token expires.

The database must already have a tdo schema in it: run tdo init once against it from the CLI. This app creates nothing.

Offline, this is a shell with nothing behind it. Reads and writes need your database, and a write that cannot reach it fails and says so rather than being queued — your list is in one place, and a copy in here that disagreed with it would be worse than an error.
