            What you are accepting

            • The token is stored in this browser. Any script that runs on this site can read it, and so can anyone who opens devtools on this device. The protection here is that this site serves a handful of hand-written files and no third-party code — not that the value is hidden from anything.
            • Use a token that is as narrow and as short-lived as you can make it. Turso issues tokens per database, which is why it is the provider this app supports: a token minted for your todo database cannot touch anything else you own. Give it an expiry — turso db tokens create <database> --expiration 7d — and mint a read-only one if you only want to look (--read-only).
            • Anyone who unlocks this device can see your tasks. Leave the box below unchecked on a shared or borrowed machine: the token is then kept for this tab only and goes when you close it.
            • Revoking is done at Turso, not here. Disconnecting removes this browser's copy of the token. It does not end the token's life — turso db tokens invalidate <database> does.
